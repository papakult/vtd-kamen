# vtd-kamen
Всероссийский торговый дом «Камень». Сайт-каталог.

[Сайт торгового дома](https://kamenvtd.ru/). Публикация идёт из ветки `main` через GitHub Pages.

## Визуализация сайта

На первом экране — 15-секундный фильм о поставках. Для компьютера и телефона подготовлены отдельные монтажные версии. Крупный фирменный знак у правого края — каменный монолит с медной прожилкой. Знак хранится в `mark.svg`. Главная ведёт в пять направлений каталога. Покупатель открывает товары прямо на сайте. Ссылки на скачивание презентации убраны.
